================================================================================
         Enhanced_STF_Detector 部署指南 — 完整环境配置流程
================================================================================

本文档包含从零开始配置项目运行环境的全部步骤。
目标：在一台有 NVIDIA GPU 的 Windows 机器上完成环境搭建并运行推理。

================================================================================
一、硬件与系统要求
================================================================================

- 操作系统：Windows 10/11 (64-bit) 或 Linux (Ubuntu 20.04+)
- GPU：NVIDIA 显卡，显存 >= 6GB（推荐 RTX 3060 及以上）
- CUDA：>= 12.1（需与 PyTorch 版本匹配）
- 内存：>= 16GB
- 硬盘：项目 + 环境约需 15GB

================================================================================
二、安装 NVIDIA 驱动与 CUDA
================================================================================

# 1. 安装 NVIDIA 驱动（如已有可跳过）
#    下载地址：https://www.nvidia.com/Download/index.aspx
#    选择对应显卡型号，安装最新驱动
#    安装完成后验证：
nvidia-smi

# 2. CUDA Toolkit（PyTorch 自带 CUDA runtime，通常不需要单独安装）
#    如需单独安装：https://developer.nvidia.com/cuda-12-1-0-download-archive

================================================================================

# 安装 PyTorch + torchvision（CUDA 12.1 版本）
# 这是最关键的一步，务必安装 GPU 版本

# 验证 PyTorch 是否识别 GPU：

# GPU: NVIDIA GeForce RTX 4090 D

# 如果输出 CUDA: False，说明安装的是 CPU 版本，需要卸载重装：
# pip uninstall torch torchvision -y
# 然后重新执行上面的 pip install 命令

九、单视频推理（一键检测）
================================================================================

# 基本用法 — 只需一条命令：
python infer.py 视频文件路径

# 示例：
python infer.py D:\videos\test_video.mp4

# 脚本会自动完成：
#   1. 视频抽帧（保留所有帧）
#   2. 加载模型
#   3. 逐帧推理
#   4. Hybrid Top-k Mean 聚合
#   5. 输出 AI 生成概率
#   6. 清理临时文件

# 输出示例：
# [设备] cuda
# [抽帧] 从视频中提取了 300 帧 (共 300 帧, 间隔 1)
# [模型] 已加载: fusion=cross_attention dim=512 temporal=True hfri=True srm=True
# [推理] 300/300 帧
#
# ==================================================
#   视频路径:   D:\videos\test_video.mp4
#   分析帧数:   300
#   AI生成概率: 0.8723 (87.23%)
#   判定阈值:   0.5
#   检测结果:   AI 生成
# ==================================================

# 可选参数：
python infer.py video.mp4 --threshold 0.6          # 修改判定阈值
python infer.py video.mp4 --batch_size 16           # 增大批处理（显存够用时更快）
python infer.py video.mp4 --checkpoint model.pth    # 指定其他模型权重
python infer.py video.mp4 --device cpu              # 强制用 CPU

================================================================================
十三、常见问题排查
================================================================================

问题1：CUDA out of memory
  → 减小 batch_size：python infer.py video.mp4 --batch_size 4
  → 或减小 image_size：python infer.py video.mp4 --image_size 192

问题2：torch.cuda.is_available() 返回 False
  → 检查是否安装了 GPU 版 PyTorch：
    python -c "import torch; print(torch.__version__)"
    如果版本号不含 +cu121，说明装的是 CPU 版本，需要重装（见第五节）

问题3：ModuleNotFoundError: No module named 'cv2'
  → pip install opencv-python

问题4：FlowFormer 加载失败
  → 确认 FlowFormerPlusPlus-main/ 目录存在
  → 确认 checkpoints/things.pth 存在
  → 检查 timm, einops, yacs 是否安装：pip install timm einops yacs

问题5：ImportError: cannot import name 'ResNet50_Weights'
  → torchvision 版本过低，需升级：pip install torchvision>=0.13.0

问题6：视频无法打开
  → 确认 opencv-python 已安装
  → 确认视频文件路径正确，格式受支持（mp4/avi/mov/mkv 等）
